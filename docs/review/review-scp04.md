# SCP04 逐项累计预览验收

日期：2026-10-26。范围：简化方案中的“每填一项就累加显示”。代码已在工作区完成，尚未提交或部署。

## 行为与操作说明

- 初始显示“已填项合计 0.00”及“已填 0/N 项”。填写合法分数后，按原权重累加贡献；合法零分计入进度，空白保持空白。
- 存在非法数字、越界或步长错误时，排除该项贡献，显示“有效项合计”及需修正项数，同时保留对应输入错误提示。
- 全部填写合法后，显示“个人总分预览”并在满足开评、同步、截止等既有限制时开放“核对并提交”。确认弹窗和提交处理继续严格检查完整评分。
- 修改、加减、清空、刷新恢复草稿及修改已保存评分时均即时重算。累计区保留回执说明，并通过礼貌级别的状态区域播报更新。

## 实现

`frontend/src/lib/decimal.ts` 新增 `partialTotal`，返回累计值、有效项数、总项数、错误项与完整状态。它与严格的 `personalTotal` 共用通分求和逻辑，以 Big.js 精确累加分子，最后统一除法及 ROUND_HALF_UP 两位小数展示；不对部分权重重新归一化。

`frontend/src/judge/ScoreCard.tsx` 使用部分预览显示累计值与进度，完整总分继续负责提交校验。后端计分、API、持久化评分数据和大屏不涉及改动。
